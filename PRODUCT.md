# PaperMerge

## Platform
Windows desktop; Python 3.13, Tk/ttk, requests and pypdf. The clean iOS-inspired appearance is a visual reference for a Windows utility, with native keyboard interaction, save dialogs and PDF opening.

## Users and purpose
Cambridge IGCSE and AS & A Level students preparing revision packs. Choose a qualification and subject, narrow papers by year, session, document type and paper/variant, review selections, then save one bookmarked PDF.

## Constraints
Preserve source discovery, all-or-nothing downloads, cancellation and atomic saves. Syllabus codes retain leading zeros. Public repositories can be unavailable; the bundled syllabus catalogue remains useful when catalogue refresh fails. Exam documents are fetched when requested and do not ship in the app.

The “Top 20 subjects” collection contains twenty curated syllabus shortcuts for each qualification. It is not an official Cambridge list or a verified popularity ranking. Some shortcuts cover archived syllabuses, including AS & A Level Computer Science (9608). Available options are matched against the loaded catalogue.

## User commitments
Clean iOS-inspired black and white with readable Windows system typography. Subject, year and paper/variant selectors support typing to filter their dropdown choices; qualification, collection, session and document type use constrained dropdowns. Exact paper variants can also be entered with an example beside the field. Results have a separate text search.

Friendly first-use and empty-state guidance explains the next action. Users can toggle individual papers by clicking a row or pressing Space, and select all or none. Find/Cancel sit above the results; Save merged PDF, Open saved PDF, progress and status stay below the scrollable results. Open becomes available after a successful save.
